# 📊 Excel Sales Dashboard

An interactive **Sales Analysis Dashboard built with Microsoft Excel**, designed to transform raw sales data into clear and actionable business insights.

## 🔎 Project Overview

This project analyzes **2,000 sales transactions** across different regions, sales channels, customer types, products, and salespeople.

The dashboard provides a quick view of business performance and helps identify sales trends, top-performing products, and areas that require attention.

## 🎯 Objectives

* Analyze overall sales performance
* Identify top-performing products and salespeople
* Compare regional and sales channel performance
* Analyze customer purchasing patterns
* Track monthly sales trends
* Build an interactive and professional Excel dashboard

## 🛠️ Tools & Skills

**Microsoft Excel**

`Pivot Tables` `Pivot Charts` `Slicers` `KPI Cards` `Data Cleaning` `Data Analysis` `Data Visualization` `Dashboard Design`
